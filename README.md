# 🎬 Movie Data Visualization using Python

A simple and attractive data visualization project built using **Python, Pandas, and Matplotlib**. This project analyzes a movie dataset and presents the insights using different types of charts.

---

## 📊 Charts Included

- 📈 Line Chart
- 📊 Bar Chart
- 🥧 Pie Chart
- 🍩 Donut Chart

All four charts are displayed together in a **2 × 2 dashboard** with attractive colors and customized backgrounds.

---

## 🛠 Technologies Used

- Python
- Pandas
- Matplotlib

---

## 📁 Dataset

The project uses a movie dataset containing information such as:

- Movie Title
- IMDb Rating
- Release Year
- Genres
- Adult / Non-Adult Category
